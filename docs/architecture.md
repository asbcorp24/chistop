# Архитектура Chistop

## Цель

Единая информационная система колледжа с функциональным покрытием уровня 1С:Колледж и современным адаптивным веб-интерфейсом.

## Принципы

1. Filament — основной интерфейс сотрудников.
2. Desktop: таблицы, фильтры, массовые операции.
3. Mobile/tablet: карточки и адаптивные действия.
4. Расписание и педагогическая нагрузка являются внешними master-data и поступают из XML.
5. Импорт идемпотентный: внешние идентификаторы сохраняются, повторный XML обновляет записи, а не создает дубли.
6. Ручные изменения импортируемых сущностей должны быть явно отделены от данных источника.
7. Все значимые изменения аудируются.

## Домены

- Core: организация, подразделения, пользователи, роли и права.
- Education: специальности, учебные планы, дисциплины, группы, контингент.
- Integration: XML, сопоставления внешних идентификаторов, протокол импорта.
- Schedule: импортированное расписание, занятия, замены.
- Workload: импортированная педагогическая нагрузка.
- Journal: посещаемость, оценки, темы и фактические часы.
- Assessment: ведомости, экзамены, зачеты, пересдачи, задолженности.
- GIA: допуски, комиссии, экзамены, ВКР, выпуск.
- Practice: виды практик, базы, договоры, направления, результаты.
- Admissions: кампании, заявления, документы, вступительные испытания, рейтинги, зачисление.
- StudentMovement: переводы, академические отпуска, отчисления, восстановление.
- Methodical, Upbringing, HR, Dormitory, Scholarship, Documents, Reports, Audit.

## XML

XML проходит стадии: upload -> validation -> parse -> normalize -> resolve references -> upsert -> post-validation -> publish.

Каждый запуск сохраняется в import_batches с checksum, статусом, счетчиками и журналом ошибок.
